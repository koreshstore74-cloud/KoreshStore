# Koresh Store 🛍️

موقع متجر إلكتروني كامل باسم **Koresh Store** — HTML/CSS/JS خالص من غير أي فريمورك، وشغال مباشرة من غير سيرفر.

## المحتوى

- **index.html** — الصفحة الرئيسية: هيدر بمشهد 3D تفاعلي (Three.js)، أقسام المنتجات، فلترة وترتيب، سلة تسوق.
- **checkout.html** — إتمام الطلب وإنشاء رقم تتبّع.
- **track-order.html** — تتبّع حالة الطلب.
- **complaints.html** — نموذج شكاوى واقتراحات + متابعة حالتها.
- **policies.html** — سياسات الشحن والاستبدال والدفع.
- **admin.html** — لوحة تحكم محمية بكلمة سر لإضافة/تعديل/حذف المنتجات، ومتابعة الطلبات والشكاوى.
- **js/** — كل منطق الموقع (بيانات، تخزين، سلة، 3D، لوحة التحكم).
- **css/style.css** — تصميم الموقع بالكامل.

## ⚠️ حاجة مهمة لازم تفهمها

الموقع ده **Static Site** (موقع ثابت) من غير قاعدة بيانات أو سيرفر خلفي. ده معناه:

- أي منتج بتضيفه من `admin.html`، أو أي شكوى بيبعتها عميل، أو أي طلب بيتعمل — **بيتخزن جوه متصفح الجهاز اللي بيستخدمه الشخص في الوقت ده بس** (localStorage)، مش على سيرفر مركزي.
- ده معناه إنك لو ضفت منتج من موبايلك، هو هيظهر ليك لما تفتح الموقع من نفس الموبايل ونفس المتصفح، لكن **مش هيظهر تلقائيًا لعميل بيفتح الموقع من جهاز تاني**.
- نفس الكلام على الشكاوى والطلبات اللي العملاء بيبعتوها — كل واحد هيشوف بس اللي عمله هو على جهازه.

### إمتى المشكلة دي بتبان؟
لو عايز الموقع يشتغل زي متجر حقيقي (منتج بتضيفه إنت يظهر لكل الزوار، وشكاوى العملاء توصلك إنت شخصيًا)، لازم الموقع يتوصل بقاعدة بيانات حقيقية زي:
- **Firebase** (مجاني للمشاريع الصغيرة وسهل الدمج)
- **Supabase**
- أو باك إند بسيط بـ Node.js / PHP

ده تطوير إضافي مش موجود في النسخة دي. لو عايز، قولّي وهنعمله في خطوة تانية — الموقع الحالي مبني بشكل يسهل إضافة الباك إند عليه بعدين من غير ما نعيد كل حاجة.

## تسجيل دخول لوحة التحكم

- افتح `admin.html`
- كلمة السر الافتراضية أول مرة: **koresh2026**
- غيّرها فورًا من تبويب "الإعدادات" بعد أول تسجيل دخول.
- كلمة السر بتتخزن (بشكل مبسط) في نفس المتصفح؛ لو مسحت بيانات المتصفح (Clear browsing data) هترجع كلمة السر الافتراضية.

## تعديل بيانات المتجر (سوشيال ميديا، واتساب)

افتح `js/data.js` وعدّل القيم دي:

```js
const SITE_CONFIG = {
  whatsapp: "201114577749",
  facebook: "https://www.facebook.com/share/1HpLuiX16D/?mibextid=wwXIfr",
  instagram: "https://instagram.com/koresh.store", // غيّره لرابط صفحتك الحقيقي
  storeName: "Koresh Store"
};
```

## رفع الموقع على GitHub ونشره (GitHub Pages)

نفّذ الأوامر دي وانت جوه فولدر المشروع (`koresh-store`):

```bash
# 1) لو لسه ماعملتش git init
git init
git add .
git commit -m "Initial commit: Koresh Store website"

# 2) اربط المشروع بريبو جديد على GitHub (اعمل الريبو الأول من github.com)
git branch -M main
git remote add origin https://github.com/USERNAME/REPO-NAME.git
git push -u origin main
```

بعد الرفع:
1. روح على صفحة الريبو في GitHub.
2. **Settings → Pages**.
3. تحت "Build and deployment" اختار **Deploy from a branch**.
4. اختار الفرع `main` والفولدر `/ (root)`.
5. احفظ، وهتلاقي رابط الموقع شغال بعد دقيقة أو اتنين على شكل:
   `https://USERNAME.github.io/REPO-NAME/`

> لو عندك دومين خاص، تقدر تضيفه من نفس صفحة الـ Pages تحت "Custom domain".

## ملاحظة عن الصور

المنتجات لما تضيفها من لوحة التحكم بتحتاج **رابط صورة مباشر** (URL)، مش رفع ملف. تقدر تستخدم:
- صور من موقعك أو من مكان استضافة صور زي imgbb.com أو Cloudinary.
- أو صور من Unsplash كـ placeholder مؤقت.
