# Koresh Store 🛍️

موقع متجر إلكتروني كامل باسم **Koresh Store** — HTML/CSS/JS خالص، متوصّل بـ **Firebase**
(Firestore + Authentication) كقاعدة بيانات حقيقية. أي تعديل من لوحة التحكم بيظهر فورًا
لكل زوار الموقع، من أي جهاز.

## المحتوى

- **index.html** — الصفحة الرئيسية: هيدر بمشهد 3D تفاعلي (Three.js)، أقسام المنتجات، فلترة وترتيب، سلة تسوق.
- **checkout.html** — إتمام الطلب وإرساله لقاعدة البيانات.
- **track-order.html** — تتبّع حالة الطلب برقم الطلب.
- **complaints.html** — نموذج شكاوى واقتراحات + متابعة حالتها برقم المرجع.
- **policies.html** — سياسات الشحن والاستبدال والدفع.
- **admin.html** — لوحة تحكم محمية بتسجيل دخول حقيقي (Firebase Authentication) لإضافة/تعديل/حذف
  المنتجات، ومتابعة الطلبات والشكاوى، وتغيير هوية المتجر وألوانه.
- **js/firebase-init.js** — إعداد Firebase (Firestore + Auth) لكل صفحات الموقع.
- **js/** — باقي منطق الموقع (تخزين، سلة، 3D، لوحة التحكم).
- **css/style.css** — تصميم الموقع بالكامل.
- **firestore.rules** — قواعد الأمان اللي لازم تحطها في Firebase Console.

## 🔥 إزاي البيانات شغالة دلوقتي

| البيانات | مكان التخزين | مين يقدر يعدّل |
|---|---|---|
| المنتجات | Firestore (`products`) | صاحب المتجر بس (بعد تسجيل الدخول) |
| إعدادات المتجر (الاسم، اللوجو، الألوان، السوشيال ميديا) | Firestore (`settings/site`) | صاحب المتجر بس |
| الطلبات | Firestore (`orders`) | أي حد يعمل طلب جديد، بس التعديل/الحذف لصاحب المتجر بس |
| الشكاوى | Firestore (`complaints`) | نفس منطق الطلبات |
| سلة التسوق الحالية | متصفح العميل (localStorage) | مؤقتة، بتتصفّر بعد إتمام الطلب |

كل المنتجات والإعدادات بتتزامن **لحظيًا (Realtime)** — لو ضفت منتج من لوحة التحكم، هيظهر
عند أي حد فاتح الموقع في نفس اللحظة من غير ما يعمل تحديث للصفحة حتى.

### تتبّع الطلب/الشكوى من أي جهاز
لأسباب أمان (منع أي حد من استعراض كل طلبات العملاء)، تتبّع الطلب بيتم **برقم الطلب بالظبط**
(اللي بيوصل للعميل بعد الشراء مباشرة)، مش بالبحث برقم الموبايل. نفس الكلام على الشكاوى —
بيوصل للعميل "رقم مرجع" بعد الإرسال يقدر يستخدمه للمتابعة من أي جهاز.

## تسجيل دخول لوحة التحكم

- افتح `admin.html`
- سجّل دخول بالإيميل وكلمة السر اللي عملتهم في **Firebase Authentication → Users**
- تقدر تضيف أكتر من مستخدم أدمن من نفس الشاشة في Firebase Console لو حبيت
- كلمة السر تتغيّر من تبويب "الإعدادات" داخل لوحة التحكم

## ⚠️ خطوة مهمة لازم تعملها: قواعد الأمان (Firestore Rules)

افتح ملف `firestore.rules` جوه المشروع، وغيّر `OWNER_EMAIL_HERE` (في كل مكان موجودة فيه)
إلى إيميلك اللي بتسجل بيه دخول في `admin.html`. بعد كده:

1. روح [Firebase Console](https://console.firebase.google.com) → مشروعك → **Firestore Database → Rules**
2. الصق محتوى الملف بعد التعديل
3. دوس **Publish**

من غير الخطوة دي، أي حد يقدر (نظريًا) يعمل حساب جديد بنفسه عبر الكود ويحاول يعدّل في
منتجاتك — القواعد دي بتقفل الباب ده وتخلي التعديل مقصور عليك إنت بس.

## تعديل بيانات المتجر من الكود مباشرة (اختياري)

القيم الافتراضية (قبل أي تعديل من لوحة التحكم) موجودة في `js/storage.js` تحت
`KS.DEFAULT_SETTINGS`. مفيش داعي تعدّلها يدويًا — الأسهل إنك تغيّر كل حاجة من
تبويب "الإعدادات" في `admin.html` وهي هتتخزن على السحابة تلقائيًا.

## رفع الموقع على GitHub ونشره (GitHub Pages)

نفّذ الأوامر دي وانت جوه فولدر المشروع (`koresh-store`):

```bash
git init
git add .
git commit -m "Initial commit: Koresh Store website"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO-NAME.git
git push -u origin main
```

بعد الرفع:
1. روح على صفحة الريبو في GitHub.
2. **Settings → Pages**.
3. تحت "Build and deployment" اختار **Deploy from a branch**.
4. اختار الفرع `main` والفولدر `/ (root)`.
5. احفظ، وهتلاقي رابط الموقع شغال بعد دقيقة أو اتنين على شكل:
   `https://USERNAME.github.io/REPO-NAME/`

### مهم بخصوص Firebase Authentication ونطاق الموقع
لما تنشر الموقع على GitHub Pages، روح على **Firebase Console → Authentication → Settings →
Authorized domains** وضيف نطاق GitHub Pages بتاعك (مثلاً `USERNAME.github.io`)، وإلا تسجيل
الدخول في `admin.html` هيرفض يشتغل من على الدومين الجديد.

## ملاحظة عن الصور

المنتجات لما تضيفها من لوحة التحكم بتحتاج **رابط صورة مباشر** (URL)، مش رفع ملف. تقدر تستخدم:
- صور من موقعك أو من مكان استضافة صور زي imgbb.com أو Cloudinary.
- أو صور من Unsplash كـ placeholder مؤقت.

اللوجو بس هو اللي بترفعه كملف مباشرة من لوحة التحكم (بيتحول لصورة مضغوطة وبيتخزن في الإعدادات).
